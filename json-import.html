JSON Entries

Each entry is one class slot: department, semester, day, period, subject and teacher. Give each semester its own timing block if it runs on a different clock than the rest — entries only clash when their actual start/end minutes overlap, even partially.

Schema Notes

  • entries[].type — choose from:
    • theory — 1 period (default)
    • theory_extended — 2 contiguous periods, shown in the routine exactly like plain Theory
    • lab_mini — 1 period, shown as "(LAB)"
    • lab_extended — 2 contiguous periods, shown as "(LAB)"
    • theory_lab — 2 contiguous periods, shown as "(Theory + Lab)"
    • filler — placeholder class (e.g. Library); add "periods": 2 for a 2-period span
  • entries[].timing (optional) — per-semester periods, duration, startTime, tiffinPeriod, and tiffinDuration.
  • Global conflict check: a teacher scheduled in an overlapping clock-time interval is automatically caught in real time.
  • Real-time resolution: use Auto-Place to search for the earliest free slot, or Add Library/Other Class to fill the slot with a placeholder.
